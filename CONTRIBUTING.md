# Contributing to Balla

Balla is a Facebook-inspired Bluesky client for phones: the chronological
Following feed rendered the way Facebook reads — cards on a warm grey canvas —
with noneof the dark patterns. Thanks for wanting to help!

## Getting started

Set up Node 22 and Expo per the [README](README.md). CI runs the typecheck,
dependency audit and icon sync; on-device behaviour is verified by the
maintainer.

## Notes for this project

- **The chronological feed is the design.** Changes never rank, Reorder,
  suggest or insert anything between a person and the people they follow. If a
  change touches the feed's order, it wants an unusually good reason in the PR.
- **Accessibility is a floor, not a feature.** Every action is a visible button
  of at least 44pt; no swipe-only or long-press-only interactions; respect the
  system font size settings. Reachability with one hand and reduced grip is a
  design constraint here, not an afterthought.
- The icons are generated by `scripts/gen-icons.py`; visual identity changes go
  through the script rather than editing committed assets by hand.
- If you can't test on a device or emulator, say what you did verify instead.
- Conventional commits; focused PRs; explain verification in the description.
- AI-assisted PRs welcome; stand behind every line and run what you can.
