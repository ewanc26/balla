Install

Balla on your phone.
Straight from the project.

Balla is in development. Neither route goes through the App Store or Google Play.

iOS, with AltStore Classic

  1. Set up AltStore Classic, which needs its AltServer app on a computer.
  2. In AltStore, open Sources, choose to add one and enter https://balla.croft.click/altstore.json
  3. Install Balla from that source. AltStore signs it with your own Apple ID.

With a free Apple ID the app stops opening after seven days unless AltStore refreshes it, and Apple limits how many sideloaded apps you can keep.

Android, from Balla’s F-Droid repository

This is Balla’s own repository, not the F-Droid catalogue. The file is built and signed by the project.

  1. Install F-Droid.
  2. In F-Droid’s repository settings, add https://balla.croft.click/fdroid/repo?fingerprint=D08709E100F8DD301ABD2A1B653BF48ADE76C918F457BDA463EDE63BBC76E612
  3. Refresh, search for Balla and install it.
